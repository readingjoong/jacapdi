## 1차선에서 고친 것
- **평가점 당김** `front_axle_ref`: Stanley 평가점 뒷축 앞 1.73 → 1.41 m, 사이는 원호로 외삽. 코너 안쪽 평형 감소
- **실선 연속성** `cross_continuity`: 급좌코너에서 옆 차로 바깥 실선을 '넘은 안쪽 실선'으로 오인 → 오른쪽 급조향하던 경로 뒤집힘 방지
- **기존 가드** (야간): 선 하나 경로 상한, 선 밟음 유지, 단계 수용, 실선 넘음 복구, 차선 변경 정착 상태기계
- **코너 감속** `corner_slowdown`: 조향 60 % 이상이면 PWM 190 쪽으로 감속

## 시뮬에서 확인한 사실
- 1차선 이탈은 반경이 가장 작은 두 코너(약 1.5 m, 1.7 m)에서 남. 속도를 낮춰도 그대로 → 기하 문제
- 시뮬 조향 바퀴각 = 명령의 0.57~0.73 (가제보 플러그인 P 제어). 실차 서보와 다를 수 있음
- 카메라 시야가 뒷축 앞 1.63~2.33 m 라 급코너에서 차로가 화면 왼쪽으로 빠짐

## 실차 시험 순서
README "실차 1차 시험 프로토콜" 절이 정본. 요지:
1. 측정: 최대 조향각과 최소 회전반경, 조향 스텝 응답, PWM별 속도
2. 2차선 회귀 (`ALGO=v3 LANE=2` 또는 base): 2바퀴 1:34 ± 5 s
3. 1차선 v3 (`ALGO=v3 LANE=1`): PWM 200 → 255. 코너 바깥 밀림 → `front.ahead_m` 0.89, 안쪽 깎기 → 0.80 이하
4. 차선 변경: 직선에서만, `lane_change_sec` 3.0, `LANE_AT` 로 2→1 ×3, 1→2 ×3, 왕복
5. 중단: 바깥 실선 완전 통과 1회, 경로 상실 정지 2회, 좌우 흔들림 3 s 이상
6. 주행 기록(ab_runs) 보관 → 시뮬 조향 지연 보정에 사용

## 남은 문제
- 1차선 급코너 진입 지연: 점선이 차 앞을 지나갈 때 '선 밟음'으로 오인해 낡은 경로 유지 → 조향 풀림, 재가속, 바깥 이탈
- 짧은 선 적합 외삽(마지막 코너), 횡단보도 구간 경계 상실
- 평가점 여유 좁음: 시뮬에서 x_e −0.26 부터 바깥 정지 급증
- 실차 미측정: 최대 조향각, 조향 응답, PWM-속도, YOLO 처리율
