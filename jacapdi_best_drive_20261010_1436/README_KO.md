### frames.csv 주요 열
- `steer` 조향 명령 (−100 왼쪽 끝 … +100 오른쪽 끝, 1010F 기준), `left_pwm`/`right_pwm` 뒷바퀴 PWM
- `a, b, c` 경로 곡선 y = a·x² + b·x + c. **c > 0 = 차로 가운데가 차보다 왼쪽 = 차가 실선 쪽에 있음**
- `n_solid, n_dashed` 실선·점선 검출 수, `other_classes` 그 밖의 검출
- `board_adc` 조향 가변저항 값 (왼쪽 끝 543, 직진 462, 오른쪽 끝 391), `traj_age_ms` 경로 지연
