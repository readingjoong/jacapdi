# 아두이노 펌웨어 사본

원본 위치: `~/jacapdi-live-car-2026-09-24/arduino/` (보드에 올릴 때는 `car_common.sh` 의 `FW_HEX` 가 원본을 가리킴).
여기 있는 것은 git 기록용 사본입니다. 고칠 때는 원본을 고치고 다시 복사하세요.

| 판 | 내용 |
|---|---|
| 1010f | 10/10 최고 주행 때 쓴 판. 조향 힘 3단계 (220/130/100) |
| 1010p | 조향 힘을 PD 로 (P 8, D 12, 최소 90) |
| 1016f | 1010f + 가변저항 기준 다시 잼 (왼쪽 530, 가운데 462, 오른쪽 400) |
| 1016p | 1010p + 같은 가변저항 기준 |
| 1016q | 1016p + D 항이 힘을 0 으로 끄지 않게 (데드밴드 밖이면 최소 90) |
| 1016r | 1016q + 가변저항 값이 0/1023 으로 튀어도 바로 멈추지 않음 (1초 넘게 계속일 때만 고장). 지금 `car_common.sh` 가 가리키는 판 |
| steer_monitor | **벤치 시험용 (주행용 아님)**. Arduino 시리얼 모니터(115200)에 -100~100 을 치면 그 조향 목표를 계속 유지, f = 모터 끄고 값만 보기. 0.02초마다 raw/avg/target/pwm 출력 (시리얼 플로터 가능) |
